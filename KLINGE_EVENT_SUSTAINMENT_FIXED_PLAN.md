# Fixed finite model: causal production versus simultaneous support

## Scope

This is a **new illustrative model**, not Klinge's own formalism, an experiment, or a claim that all modeled histories are metaphysically possible. We inspect it to clarify the dependence question in [Klinge's book audit](KLINGE_EMERGENT_PANPSYCHISM_AND_CAUSAL_CLOSURE_AUDIT.md). Klinge explicitly says a brief phenomenal event exists independently once produced, whereas a longer state is maintained by repeated production (printed pp. 91–92); he elsewhere says the emergent cannot survive functional disintegration of its base (p. 182). The intended target here is **a specified continuing base**, not Barnes' more general definition involving accompaniment by some concrete objects.

## Model fixed before checking

Use a finite discrete history, not fundamental time: a base indicator `B_t∈{0,1}`, and production `P_t=B_t` in the main model. When `P_s=1`, posit an event active at samples `s,s+1,…,s+d−1`, with `d≥1` fixed, without early termination. For times `t≥d−1`, define a coarse active-state indicator `E_t=OR_{j=0}^{d−1} P_{t−j}`. This indicator means only that at least one produced event is active. It is not a claim that the events form a single lived experience or belong to the same person.

For each `d=1,…,8`, enumerate all `2^d` formal length-d histories. Count `E_t=1, B_t=0`; compare with the proposed exact number `2^(d−1)−1`. Count pairs of windows with identical current `B_t` but different activity where applicable. Prove that, on this unrestricted formal domain, `E_t⇒B_t` for every window iff `d=1`. Report exact counts rather than population or real-world probabilities. Also check a single sustained-period example and a two-start overlap example to distinguish continued event activity, event number and a stipulated state label.

As a separate **conditional repair**, allow `P_t≤B_t` and require every produced event's full lifetime to remain inside the period when `B=1`. On a finite horizon only within-horizon times can be checked; no claim about an unobserved future follows. Enumerate all binary `(B,P)` histories of length six for durations 1–4, rejecting `P_t>B_t`, and check that this lifetime-coverage condition is equivalent to `E_t⇒B_t` at every observed time. State the exact counting domain and include finite-horizon boundary cases. This is a restriction on admissible histories, not a derivation that the real world obeys it. Another option is causal early termination; neither needs to be metaphysically primitive simply because it is added to a mathematical model.

The sample indices and Boolean variables are bookkeeping, not measured 100 ms experiential events. Do not assert a physical, phenomenal or metaphysical counterexample, assign individuals, or infer a person from a connected active interval. Do not infer that Klinge accepts all formal histories or that his theory is inconsistent without an independent assumption that the relevant history is admissible. Distinguish past production, current accompaniment by the designated base, sustained aggregate activity, simultaneous phenomenal unity, person identity and ontological grounding.

## Post-result extension: nonoverlapping event sequence

After the first calculations, note that the primary `P=B` model can generate overlapping event tokens, whereas Klinge describes successive short events. Before calculating a new sample-wide stratum, add a stricter formal domain: within the six-slot joint histories above, require that distinct event starts be at least `d` slots apart. Report eligible and supported counts and recheck the same equivalence of lifetime coverage and simultaneous designated-base support. Include the fixed nonoverlap witness `d=3`, `B=(1,1,1,1,0,0)` and `P=(1,0,0,1,0,0)`: the events are sequential, but the second extends beyond the indicated base. This isolates persistence without relying on overlapping episodes. It is an outcome-informed model refinement, not a claim that this history is physically or metaphysically admissible.
