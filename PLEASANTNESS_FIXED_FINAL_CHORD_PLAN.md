# Fixed retrospective comparison: prior chord and final-chord pleasantness

This exploratory plan was written after reading the published findings, the authors' R Markdown and stimulus metadata, and the data schema/factor counts, but before computing the summaries below. It is **not** a prospective preregistration or an independent replication. Arthurs, Lahdelma and Eerola already report roughness and familiarity effects. Here the point is to connect their experiment to the narrowly specified present-stimulus-only failure condition and quantify person-level uncertainty without claiming a new effect.

## Inputs and processing

Use the public [authors' repository](https://github.com/tuomaseerola/penultimate_chord) at commit `010777ada95da0044492d14865a162d7bc2874f8`. Read its SPSS file `data/PleDisso1.sav` and `data/stimulusTable.csv` with verified SHA-256 values as fixed in the analysis script. The file has an empty participant block as well as completed blocks. Exclude rows with missing participant, question, rating, roughness or familiarity; do not use gender, age, musical background or the potentially identifying participant codes in output. Require exactly one valid rating of each question 1–56 for a retained participant, integer ratings 1–7, and no duplicate `(participant,question)`. Map question number n to row n−1 of `stimulusTable.csv` following the authors' row-order code; verify all stimulus-table conditions against each row's roughness/familiarity codes. Stop if any condition fails. Use all complete participants including those with undisclosed gender; the repository's main mixed model excludes gender 'Other', so this is not a replay of that model.

For each participant and each of the seven keys, hold the final chord fixed within key and compare the eight penultimate contexts. Compute the four 2×2 roughness/familiarity cell averages per participant (two penultimate-chord types times seven keys). Report the overall high minus low *modeled familiarity category* contrast, the corresponding high minus low roughness contrast, the roughness contrast separately in each familiarity category, and all four cell means. Bootstrap whole participants 10,000 times with seed 9381 and use percentile 95% intervals for these four contrasts. These are selected post-publication estimands, conditional on the fixed stimulus sequences, and do not generalize to all chords or listeners. Familiarity is a corpus-derived predictor category, not an individually measured feeling of familiarity. Roughness is similarly a modeled stimulus category, not an isolated manipulated variable.

For the last-chord-only rule, allow an arbitrary constant for each *participant and key*, but no dependence on previous chord, trial order or other context. On these observed complete blocks the least-squares optimum is the participant–key mean. Report the in-sample RMSE of this unconstrained oracle and the corresponding fraction of variation around the grand mean. This is a descriptive finite-table fit floor, not prediction, population error, experience error, or a causal estimate. To distinguish noise from systematic context variation, also compute the between-context contribution after averaging ratings over people within each key, compared with the same within-key oracle. This still includes sampling noise and is not independent evidence. Report 56 stimulus means only if aggregate; no individual responses.

Interpretation: positive familiarity contrast or nonzero sample floor is not by itself proof of a population effect, nor a comparison to a measured brain mismatch. A bootstrap interval excluding zero is compatible with a prior-sequence effect on the instruction-targeted rating under randomization and sampling assumptions. Since changing chords simultaneously changes pitch content, tonal relationship, voice leading, sensory roughness and predicted familiarity, it cannot causally isolate any one of them. No temporal local processing assumption entails fundamental time; experience is accepted but neither its identity nor subject boundaries follow from a report. The authors explicitly warn whole-sequence and final-chord pleasantness were not clearly separable.
