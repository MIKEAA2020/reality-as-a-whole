# S09 EEG–report feasibility: analysis plan

This is a **post-hoc single-person analysis plan**, written after earlier inspection of this participant's reports and exploratory POz spectra. It is not prospective preregistration, and the held-out runs are held out from *fitting*, not untouched by all prior inspection. The fixed split and rules below are written before running the analysis in this document; do not change them based on the test scores. The aim is feasibility of concurrent report agreement, not inference about experience, subjects in general or causal mechanisms.

- Use documented rivalry scans **1–3 for training**. Test rivalry scans **5 and 7** as later-run transfer within the same participant. Examine smooth replay scans **4 and 6** and instantaneous replay scans **8 and 9** separately as additional cross-condition transfer, not independent replication. Replay can be based on earlier rivalry reports; scans 4 and 6 have a post-hoc timing resemblance. Scans, trials and windows are not independent subjects; no p-values or population uncertainty claims.
- Reconstruct reported state as in the existing coverage analysis: each 42 s trial begins at its EEG trial marker; start unknown, then carry each code 1/2/3 forward until the next event or trial end. Analyze the 21 non-overlapping 2 s windows per trial. A window is pure only if every report sample has the same code 1 or 2; mixed, unknown or a transition within the window is unresolved. Abstain whenever a `bad_epoch` sample occurs. All five trials and 105 windows per run count in the full-grid denominator.
- EEG feature: POz, mean-subtracted symmetric Hann window; log10 ratio of power projected at the lower and higher stored tag frequencies. This is the same simple projection previously inspected on scans 1–3, not the papers' optimized spatial/RLS extraction. Train one scalar nearest-centroid rule: mean feature for each report code across eligible training windows, classify by the nearer mean, ties to code 1. No test-set fitting, threshold selection or hyperparameter tuning. Stop if either training class is missing, any eligible feature is nonfinite, or necessary inputs are invalid.
- **Baselines:** training-set majority class (ties code 1); and a time-only rule using the 21 within-trial window positions, predicting the most frequent eligible training label at that position, with ties/empty positions falling back to the training majority. Apply the same artifact abstention as the EEG rule. A time-only control may capture task timing or replay structure; it is not a randomized causal control.
- Report each held-out scan's pure-clean confusion matrix, class counts, accuracy, and balanced accuracy if both classes occur. Also report full-grid success `correct pure-clean windows / 105`, and full-grid disagreement/unresolved `1 − success`: every mixed, unknown, transitioning or artifact-affected window is counted as failure, not as a wrong experience. Include all three models and all per-run outcomes, not just favorable runs. Full-grid score is a **window-level** conservative report-agreement metric, not the previously calculated sample-level floor; thresholds from other prospective protocols do not apply.
- Input hashes are checked against the earlier nine scan inspection JSONs. Run with bounded local files and do not publish raw EEG, reports, event sequences, identifying filenames or DICOM metadata. Honor the dataset's noncommercial research terms and cite Roy and Jamison. Synthetic tests must cover feature direction, fit-only training, tie rules, time baseline, confusion counts, abstention, and invalid inputs.

Good or bad performance is not an estimate of report-to-experience failure. No statistically independent participants, randomized probes, no-report ground truth, causal intervention, trial-level eye/replay lineage, or fMRI temporal alignment is supplied here.
