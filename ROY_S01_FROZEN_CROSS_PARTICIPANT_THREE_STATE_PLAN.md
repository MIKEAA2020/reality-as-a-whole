# Frozen S09-to-S01 three-state EEG/report transfer plan

Written after the S09 development pilot and before accessing S01 EEG contents or report outcomes. This is a post-hoc analysis of a published dataset, not a preregistered prospective experiment. S01 is a new participant for this three-state procedure; it is only one test person, not a population validation.

- Verify the 13 supplied MAT filenames and Dropbox content hashes. Keep raw files only in ignored `.arena` storage; do not publish EEG, raw event series, sensitive metadata or private links. Check input size, hash, channel, sampling, frequencies, mask, trial boundaries and event ordering; stop for unresolvable incompatibility.
- Prespecify S01 rivalry scans **1, 3, 5, 7, 10 and 12**, from the [release README](https://zenodo.org/records/5035511/files/rivalry-eeg-fmri-upload-readme-20170225.pdf?download=1) and [pinned reanalysis mapping](https://github.com/Aubrey-Lyu/BR-project/blob/b8ca204024a4f7151645c6c2e908eb564203ac66/info_scans_conditions.m). Both may derive from the same source and do not independently establish the acquisition truth. Do not evaluate replay as if independent; no participant-specific tuning.
- Use the exact stored training model in the [S09 three-state receipt](verification/roy_s09_three_state_pilot.json), produced in commit `c982167`, and its documented thresholds, majority and timing rules. Do not use S01 data to estimate normalization, lags, thresholds, feature direction, train parameters or select favorable runs. Validate that stored model against the committed file hash before scoring. Code labels 1/2/3 follow release documentation, subject to verification; no per-participant label remapping.
- Reuse the prior parser and 2-second POz tag-ratio feature, 75%-same-report window rule, full denominator, artifact abstention and baseline definitions. Perform schema and timing checks blind to performance; do not reinterpret any check using held-out outcome scores. If the assumptions cannot be applied, stop rather than silently adapt them.
- Report each rivalry run and pooled 3×3 confusion matrices, class-specific recall, macro recall when defined, and accuracy among labeled-clean windows, plus all-window correct fraction, unresolved and artifact counts and overlap. Compare exactly the frozen S09-majority and S09-slot rules. If S01 has no mixed windows, say so; zero denominators give undefined recall rather than zero. No p-values, participant-level confidence interval or claims of independent windows.
- After the fixed test, clearly separate any diagnostic data-quality observations from hypothesis evaluation. Interpret performance as S09-to-S01 report-code transfer under provisional timestamps and label conventions, not measurement of experience, neural mechanisms, consciousness incidence or spatial phenomenology. Do not refit the S01 test outcomes as if still held out.
- Independently test model immutability, hash handling and pooled accounting; refresh indexes and run focused checks. Do not request S01 again or send correspondence.
