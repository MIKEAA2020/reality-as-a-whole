# Retrospective plan: early exposure to predictive colored displays

The prior audit already established that actual red/green/blue items occur only on rare trials in the recorded SART displays. This plan is written after seeing the study and earlier model and contingency results, but before calculating the comparisons below. It is exploratory, not a preregistration or a blinded analysis.

1. For each subject in each experiment, order all recorded SART rows by numeric block and trial, including fixed/fast/slow triggers, and identify the first and tenth recorded displays containing an actual RGB item. Check that both are rare triggers, array lengths and labels match and identifiers are unique. Do not filter by response, accuracy or RT when determining exposure order. Report unavailable occurrences if any and distinguish recorded from scheduled or seen trials.
2. Summarize response category (correct, incorrect, or missing/unusable accuracy), trigger, color category, and block at the first and tenth RGB occurrences. For participants with usable binary accuracy at both occurrences, estimate the paired change in accuracy (tenth minus first), approximate two-sided 95% paired-t interval and exact two-sided McNemar p value; show the full paired table, not just significance. Report experiment 1, experiment 2 and pooled results separately. The pooled analysis combines distinct experiment/subject identities. These three comparisons are retrospective and unadjusted. Include available-case single-occasion percentages and missingness, which do not condition on later response for their denominators.
3. The tenth occurrence is an operational early-exposure comparison, not a prespecified developmental theory or a causal manipulation. Trigger mix, stimulus category, elapsed time, block and repeated exposure can change jointly; selection into response-complete pairs and differing RT/accuracy filtering versus published models matter. Previous reward training, instructed expectations, rapid learning, stimulus timing and unrecorded experience prevent equating first occurrence with no knowledge. Nulls are not equivalence. Do not interpret change or no change as evidence of consciousness, recoupling, or an isolated warning effect.
4. **Amendment after the first calculation:** All 100 first RGB events were fixed-triggered and all 100 tenth events were fast/slow-triggered, making the primary exposure contrast completely confounded with trigger. Before computing any further results, also compare first and tenth RGB events *within each trigger category*, separately for fast and slow (and fixed as a descriptive sensitivity check), using the same outcomes, paired estimators, and experiment/pooled summaries. This conditions on an adaptive trigger, changes the definition of exposure, and does not measure learning from all preceding colors. Clearly label these additional nine unadjusted tests as post-result exploratory follow-ups, not a fix for causality or selection bias. Do not compare significance across groups as evidence of differences.
5. As a filter diagnostic, verify that response, RT and binary accuracy are jointly present or absent on RGB events and report how many of the selected first and tenth exposures have RT below 200 ms. The comparison still uses all recorded usable accuracy values as originally planned, without the published RT filter.
6. Keep participant-level values in memory only; commit aggregate output, script and synthetic plus opt-in archive tests. Run relevant prior tests, project regression checks, regenerate inventories, and update the audit with bounds and provenance.
