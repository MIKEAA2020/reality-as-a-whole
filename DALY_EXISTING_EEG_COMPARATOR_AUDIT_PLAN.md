# Existing Daly EEG comparator: fixed metadata audit plan

This is a **retrospective** source and metadata audit, not an independent preregistration. Before fixing these checks, we had already read Daly's dataset paper and our [earlier event audit](DALY_MUSIC_EEG_AND_EVENT_ALIGNMENT_AUDIT.md), inspected the public pipeline's README, configuration, parser, feature-extraction code and published summaries, and viewed the opening of one event TSV. No EEG signals or derived trial-level output tables were obtained.

Pin the independent [music-cognition pipeline](https://github.com/xinlinwang970-lab/music-cognition-eeg-pipeline-ongoing-/tree/634fa01848731ad2d5c88f6b3483b48dc9ba8725) and [OpenNeuro ds002721 1.0.3](https://github.com/OpenNeuroDatasets/ds002721/tree/3972f19d2846be4f283fe21c7fe39a1a11efda99); verify the event blob identity relative to the previously audited v1.0.2. Examine all experimental runs 2–5, counting actual `788` rows, their duration values, and whether any marker in each candidate music-onset window `[t,t+20)` has (a) a question code `800–807` or (b) answer/response code `901–909` or `833–841`; use a separately reported `[t,t+12)` control. Partition output by exact `t` versus strictly after `t` and compare the next `788` as a separate risk. Record a distribution of first positive question and answer/response marker offsets relative to start. Do not treat a converted event marker as proven screen onset, answer or physical signal alignment.

For each exact timestamp in the open interval `(t,next t)`, find co-occurring exactly-one question, exactly-one `901–909` and exactly-one `833–841` marker after collapsing identical codes. Compare `answer−900` with `response−832`; count equal/different triples and intervals with at least one disagreement. This is a **literal codebook consistency screen**, not an assumption that equal-time marker meanings are fully validated or that different marker families must have the same acquisition semantics.

Finally, execute the **pinned upstream parser function** against source event files without EEG. Compare its own output when the same event rows are reordered solely within identical timestamps (original vs reverse-within-ties); compare three targets and its stimulus ID per music-onset interval. This is a robustness diagnostic, not a claim that original files have arbitrary order, that the alternative sequence is ground truth, or that source summaries were produced under the local dependency version. Equal-timestamp marker row order is not by itself a documented sequential chronology. Preserve outputs only as aggregates, and record the pipeline source hash, exact local software versions and tree/blob pin. Do not publish subject-level records. Recomputed neural correlation is impossible without actual EEG and upstream outputs, and this audit must not imply otherwise.

These checks were selected after seeing the pipeline and a sample and are exploratory. They concern a specific existing analysis, not all results in the paper or every possible interpretation of the dataset. A robust result cannot be presumed either positive or negative solely from successful execution; missing timing, code and artifact validation remain explicit blockers.
