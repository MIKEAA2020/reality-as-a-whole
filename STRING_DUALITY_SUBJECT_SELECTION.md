# String theory, duality and the selection of subjects

## Decision

String theory's description of multiple interacting excitations is congenial to the user's proposed plural experiential reality, but neither those excitations nor the theory's dualities supply a rule selecting subjects. We can nevertheless extract a useful **constraint** on any such rule:

> If two dual descriptions are taken to be complete descriptions of the same underlying experiential actuality, a change of description must not by itself change the subjects or their experienced character.

This is a **conditional interpretive requirement**, not a theorem that physics has established an experience map. Empirical equivalence alone does not logically rule out a proposed additional experiential structure that distinguishes the descriptions; such a proposal would add a substantive ontological distinction not supplied by the duality. Nor does the condition imply that only one subject exists. A duality-consistent selector can select any number of subjects.

A circle-compactification example makes the constraint concrete. A naive rule that counts *wound strings* as subjects gives different counts in the two dual descriptions, even for a simple state with zero total momentum and winding. The rule fails **if it is applied in the same literal form in both frames** and if duals describe the same experiential actuality. One may instead transport a selector or an additional physical reference system through the duality; that is a legitimate option, but must be stated rather than silently identifying “wound” as intrinsically special in both frames. Passing duality consistency does not determine the correct selector.

The following is established string-theory machinery used for a new problem-specific audit, not a claimed discovery of T-duality, a new string model, or empirical proof of string theory.

## 1. Existing physics: momentum and winding are exchanged

In the standard weakly coupled, flat closed-string theory with one circle of radius `R`, a state carries an integer momentum number `n`, an integer winding number `w`, oscillator quantum numbers, and noncompact momentum. For fixed oscillator contribution, the compact contribution to its noncompact mass squared is

```text
m²_compact = (n/R)² + (wR/α')²,
```

with the usual physical-state and level-matching constraints. The conventional T-duality dictionary exchanges

```text
R → R' = α'/R,       n → n' = w,       w → w' = n.
```

The compact mass term is unchanged. In a full treatment, the remaining state, right-moving fields, background dilaton and coupling also transform; equality of this single mass term is **not** by itself a proof of full physical duality. For the standard derivation and interaction discussion see [Polchinski, *Dualities of Fields and Strings*](https://arxiv.org/abs/1412.5704), section 3.1. For philosophical alternatives about the interpretation of dual descriptions see [Huggett, *Target space ≠ space*](https://arxiv.org/abs/1509.06229).

This model is a special background, not a demonstrated description of our universe. The example below uses the closed bosonic string for a clean calculation; its tachyon and failure to give a realistic particle spectrum make it **illustrative only**, not a candidate model of a human brain. Its circle is one coordinate in a chosen description, not proof that fundamental reality has a preferred spacetime or external time.

## 2. A two-excitation counterexample to one naive subject rule

Set `α'=1`, take `R=2`, and choose a free, two-closed-string Fock state with compact labels

```text
(n,w) = (+1,0) and (−1,0).
```

Choose transverse noncompact oscillator polarizations with left and right levels `N = N̄ = 1`. Because `n w = 0`, these satisfy the relevant level-matching condition regardless of the common sign convention; the oscillator mass offset is zero in the usual bosonic normalization. The example has **zero total momentum number and zero total winding**, although each excitation separately has nonzero momentum. In units with vanishing noncompact momentum, each excitation's compact contribution is `m² = 1/4`.

The T-dual description has `R'=1/2` and labels

```text
(n',w') = (0,+1) and (0,−1).
```

Each still has `m² = 1/4`; total winding and momentum numbers are again zero. Suppose, only for this audit, someone proposes:

```text
S_w: count one subject for each excitation with nonzero winding.
```

Applied literally with the same words in both descriptions, `S_w` gives **0** in the first and **2** in the second. The two Fock excitations have opposite charges and are not being distinguished by imaginary labels on otherwise identical particles. The arithmetic exposes a *representation dependence of this proposed rule*, not evidence that any excitation is or is not conscious. Interactions can split and join strings, so even a perturbative string count would need a separate persistence and subject-combination account.

In particular, this example does **not** show that the separate rule “one string is one subject” changes its count under this T-duality: the displayed map preserves the two-excitation count. That separate rule remains unsupported for other reasons, including interacting strings, binding and subject unity.

## 3. The crucial distinction: transform the rule or privilege a frame

Let `D` map a complete physical description and its relevant structures to a dual one. A subject selector that returns a set of subjects `S` should be **equivariant**: its output in the dual description must correspond to the dual image of the original output. Merely checking that the *number* of subjects is equal is weaker than matching their incidence and qualitative contents.

There are three different proposals:

1. **Unqualified same-form winding rule.** Declare “nonzero winding in the current description is the criterion” in both frames. The example violates the conditional duality-consistency requirement.
2. **Transported selector.** Begin with the winding predicate in one frame and transform the predicate with the state: in the dual frame the corresponding predicate is nonzero **momentum**. Both descriptions then give the same count for the same criterion. Duality does not forbid constructing such a covariant observable; the remaining question is what independently justifies giving that particular criterion experiential significance.
3. **Additional distinguished structure.** A physically specified probe, boundary condition, preparation or other structure might single out a useful frame or relational criterion. It must itself be mapped by D; merely writing “the first frame is fundamental” is an extra stipulation. A genuinely duality-breaking ontological choice is possible as a philosophical hypothesis, but cannot be advertised as the same complete duality-equivalent actuality without explaining the distinction.

The invariant-content interpretation is therefore a methodological condition adopted for this candidate, not a proof that all duality interpretations are equivalent. An internal finite observer need not have epistemic access to all of the duality map for its experience to be real.

## 4. Duality-consistent numbers do not choose a subject or a feeling

Define, for the compact labels,

```text
p_L = n/R + wR/α',        p_R = n/R − wR/α'.
```

Under the above T-duality, `p_L` is unchanged and `p_R` changes sign, so `I = p_R²` is invariant. The two excitations above both have `I = 1/4` in both descriptions. This is a standard momentum-sector invariant, **not** our earlier phase-frustration measure and not a validated physical marker of discomfort.

Two deliberately simple criteria `I > 1/8` and `I > 1/2` are both duality-consistent, yet they disagree on this state. This demonstrates that **duality consistency alone does not fix an experiential selector**; these threshold rules are formal examples, not plausible claims that a bosonic string experiences something. Likewise, invariant organization does not automatically select whether the associated character is unpleasant, pleasant or neutral.

The user's proposed dissonance principle therefore needs to be expressed in terms of actual physical, relational quantities with a correctly transformed dual dictionary. The [earlier phase-network score](VIBRATIONAL_DISSONANCE_EXPERIENCE_TEST.md) was a classical, effective oscillator model; it has not been derived from a quantum string state, nor shown to possess this T-duality covariance. A sign flip or redefinition of a right-moving mode is not by itself a change in phenomenal valence; the interactions and reference structure must be transformed as well. A genuine invariant *and* a noncircular, empirically grounded subject/quality rule are still required.

## 5. Is string theory better than loop quantum gravity for plurality?

**A suggestive starting point:** string theory can describe diverse, interacting excitations in a common framework, and is already an effort to include gravity together with other sectors. That fits the intuitive aspiration of one reality with multiple organizations.

**No demonstrated advantage in the required sense:** many excitations do not establish many subjects. Loop quantum gravity also has multiple quantum-geometric configurations and admits matter-coupling constructions; see [Bodendorfer's introduction](https://arxiv.org/abs/1607.05129). Neither approach presently provides a justified subject selector, a map to felt character, or a demonstrated account of human brains from its fundamental degrees of freedom. Comparing “strings” to “one spin network” is not an equal comparison of physical subsystems, let alone experiential ones.

**Shared difficulty:** gravity and gauge constraints complicate independent local subsystem factorization in both settings; operational subsystems can still be constructed with additional care. See [Donnelly and Freidel](https://arxiv.org/abs/1601.04744). A physical subsystem is not automatically a subject. String theory also has dual descriptions in which the fundamental-looking objects can change, making a duality-covariant experiential proposal especially important rather than making plurality impossible.

Run `python verification/string_t_duality_selector.py`. The standard-library [audit output](verification/string_t_duality_selector.json) checks 195 rational radius/charge cases in the `n w = 0` sector, where equal left/right levels can satisfy level matching. It checks compact mass, `p_L`, `p_R` and `p_R²` under the dictionary, and the concrete 0-versus-2 naive-label example. It tests **only the stated free-spectrum arithmetic**: it does not prove string duality or its interaction equivalence, compute actual string states beyond those labels, validate an experience metric, or solve quantum gravity.

Next, the worthwhile technical task is to specify a *relational, physically accessible* organization and its dual image—one with enough dynamics to distinguish two candidate subject boundaries and measurable content. If it cannot be constructed without assuming the consciousness rule, record that failure. A finite toy comparison is a consistency check, not evidence that our universe is the chosen background. Linking such a candidate to the existing human experience/assay constraints would remain a separate requirement.

The user's strong `possibility = actuality` thesis is not altered: the two dual descriptions are not presented as two separately actual worlds or as possibilities awaiting realization. Within the stated interpretation they are two representations of the same hypothetical model; its actual applicability to our universe remains unproved. Local spacetime and time emergence, the cutoff-to-continuum instrument problem, and first-person character remain open.
