# Metadata eligibility amendment

The fixed plan's exact three-row requirement was too restrictive: the first complete structural check found only 7 of 112 event files met it, all in 2 people; 105 failed. Consequently the planned primary held-out comparison and oracle are **not interpretable as the intended dataset benchmark** and will not be reported as a result. The analysis script must suppress them. This is not a preregistered prospective study; the plan was written after two example files and paper methods had been inspected.

For a separate, explicitly post-inspection metadata feasibility description only, identify the one event row in each file whose `stim_intensity` is neither empty nor `n/a`, require the original primary flags to be binary, and record counts, per-patient annotation availability, marker duration, intensity bin, same-patient exact-current mixed-annotation groups and event structure. Report only aggregates. Do not assume extra rows represent controls: their semantic roles require the sidecar and other evidence; a missing post marker is not a reason to invent one. Record whether each event's current-bearing row includes explicit lower-intensity/sham wording, but its absence does not establish absence of experimental controls or of other files. In this amended description the within-patient/current oracle is exploratory, not an independent validation. No additional label-optimizing, neural, inferential or causal analysis is authorized.
