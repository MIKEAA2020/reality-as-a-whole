# Subject boundaries, higher-body coupling and report causality

**Energy-interface continuation:** [sphere, work relation and candidate incidence](ZERO_ENERGY_SPHERE_WORK_SUBJECT_INCIDENCE.md) repeats the record-local versus joint-relation test behind the finite relative-clock interface with nondegenerate work occupations and a targeted h-memory.

## Main result

The [integrated sphere–clock model](ZERO_INTEGRATED_SPHERE_AUTONOMOUS_INCIDENCE.md) left two issues open: whether the old candidate-subject graph includes the new interface, and whether a quality assigned using the richer work current can be reported as though it belonged to the confined record subsystem. Both can now be sharpened.

1. The actual constraint contains a **five-body record–work term**, plus a six-body term when the targeted memory couples. Every direct two-body record–work Pauli coefficient of this interface is zero. A graph built only from two-body coefficients can therefore miss a genuine interaction entirely; the former four-node subject selection is not a selection derived from the full constraint.
2. For the two actual five-ray code states `Ψ₀,Ψ₁`, the entire confined record density is identical, but a hypothetical report of the richer J-probe together with the locally available record would distinguish the preparations. Such a report **cannot be generated by an operation on that record subsystem alone**. If the two interventions and reports were spacelike separated in a suitable physical realization, a reliable report of that kind would give a signalling channel. The present model does not establish such a spacelike realization.
3. Conversely, an explicit **extension beyond the original protected code** shows that the same specified constraint can physically transmit information from the work factor into a coherent record for some other preparations. We prove this at sufficiently small scalar-clock readings in the continuum; a finite-grid example gives trace distance about **0.8876** at φ=5. This is permitted by the model's interaction, not faster-than-light signalling and not evidence that the original confined record experienced anything.

These results constrain the bridge and the subject-boundary problem; they do not identify an actual subject or prove that experience is local. The user’s traveler/player is not identified with the record subsystem or a confined inhabitant.

## 1. The full constraint contains interactions omitted by the old graph

Write the four work bits as `(M₁,W₁,M₂,W₂)` and let `a=|0110⟩`, `b=|1001⟩`. The original standalone exchange and its first work-current probe are

```text
G=|b⟩⟨a|+|a⟩⟨b|,
J₁=i[G,N_(work M₁)],        J₁²=P_act=|a⟩⟨a|+|b⟩⟨b|,
J₂=−J₁.
```

The actual integrated constraint uses

```text
K=Z_R₁ J₁,            h=(P_act−Z_R₁J₁)/2,
C̃=...+h+0.4 E_5 h σ_yᴮ+...
```

The explicit Pauli expansion of J₁ is

```text
8J₁ = −XXXY + XXYX + XYXX + XYYY
      −YXXX − YXYY − YYXY + YYYX,
```

where the four letters follow the work-bit order above. Each term acts on **all four** work bits. Consequently the `−Z_R₁J₁/2` part of h is a five-body record–work interaction, and the `−0.2 E_5 Z_R₁J₁ σ_yᴮ` part of C̃ is a six-body record–work–B interaction, also conditioned on geometry.

In particular, every Pauli coefficient containing R₁ and **only one** work bit is zero, even though

```text
[[h,X_R₁], X_(work M₁)] ≠ 0.
```

This is an exact operator statement about the given logical tensor factors, not a conclusion from the chosen state. A selector that only reads pairwise Hamiltonian coefficients would miss the coupling. A hypergraph, a cut-sensitive multi-body influence rule, or a physical intervention test could retain it, but none is uniquely compelled here. The earlier L-selector used a separately specified four-block structural Hamiltonian; it has not been recalculated from the full constraint and cannot be promoted to a demonstrated subject boundary.

The J₁ operator is the current of the *standalone* G exchange, not generally the full constrained current `i[Ω,N_(work M₁)]`. Calling it a current probe does not identify the two.

## 2. Exact local-report constraint on the actual sphere state

Let `Ψ₀` be the actual five-ray state and `Ψ₁=Z_(work M₁) Ψ₀`. As established and rechecked for both sphere instrument settings,

```text
K Ψ_h = (1−2h) Ψ_h,      ρ_R(Ψ₀)=ρ_R(Ψ₁),
ρ_R = ½(|01⟩⟨01|+|10⟩⟨10|).
```

The reference blocks H₁,H₂ are fixed, so the complete old candidate subsystem `S={H₁,R₁,R₂,H₂}` also has the same reduced density in both preparations. The phase flip is an operation on the work factor; comparing these two prepared inputs is not a mere change of basis. It is not assumed to be a zero-work intervention, and it need not actually occur.

Put the same initial geometry, detector and memory states alongside either code state and evolve with the same integrated constraint. Since Ψ_h is an h eigenstate, its evolution is `Ψ_h ⊗ U_h(φ)|η⟩` up to spectator reference factors. Thus the local S density remains equal for the two cases at every φ, although the richer states and targeted B statistics can differ. Every fixed quantum instrument acting **only on S**, even with an identically prepared, initially uncorrelated local ancilla, has exactly the same output distribution in the two cases. This follows from complete reduced-state equality, not from comparing only averages.

In contrast, the proposed J-quality law for S₁ identifies its sign with J₁. In the two code states, a joint ideal readout has

```text
          r=Z_R₁       J₁
Ψ₀:          ±1         r
Ψ₁:          ±1        −r.
```

Both r values have probability 1/2. J₁ alone has the same unbiased distribution in both states; **r together with J₁** reveals which state was prepared because `rJ₁=K`. Suppose, in addition, that a subject confined to S can reliably report the proposed J-sign and can access its own local r. If the report error is at most `ε<1/2` in each relevant condition, their parity identifies the preparation with success at least `1−ε`. For equally likely preparations the mutual information is at least `1−H₂(ε)>0` by the binary error bound. With symmetric report error ε the total-variation distance of the two reported `(r,sign)` tables is exactly `1−2ε`.

Thus these assumptions cannot all hold at once:

- the J-sign is the locally experienced and reliably reportable quality of S₁;
- the report is generated entirely by a fixed local quantum instrument on S with the same ancillary preparation;
- the two specified preparations are available.

This is a **conditional compatibility theorem**, not evidence of an actual subjective report. If work and S were controllably spacelike separated and the report emerged at S before any causal influence, the hypothesized report would create an operational signalling problem. The present minisuperspace/encoded apparatus has no established spacelike embedding, and the record–work interaction above is not spacetime local, so the physical model itself does not demonstrate faster-than-light communication.

Several substantively different resolutions remain: the relevant subject might include work or another interface; the richer value might not be locally reportable; the physical/experiential law could differ from J; or the required spacelike independence might fail. Which is correct is not decided by the quantum density matrix alone. In particular, a richer player/traveler is not a confined piece, and no inhabitant is assumed to register richer-domain activity.

## 3. A continuum influence result beyond the protected code

The equality of S densities for Ψ₀ and Ψ₁ is a **code- and preparation-specific** result. It does not say the full operator has no cross-boundary influence for every possible state. To test that, extend the explicitly defined h operator from the two-dimensional code to the full active work sector and both R₁ basis states. This is a new allowed-state assumption about the operator's domain, not a hidden state already shown to belong to the earlier code.

Prepare R₁ in `|+x⟩`, the other reference/record factors in fixed product states, and work in an eigenstate `|j⟩` of J₁ with `j=+1` or `j=−1`. Both inputs have the same R₁ density. Choose the same normalized geometry–D–M¹–M²–B packet `|η⟩` in both. On the active work support, h is `(1−Z_R₁J₁)/2`. Work J₁ commutes with the constraint, while the two R₁ branches experience the two positive-frequency operators `Ω₀,Ω₁`.

Define

```text
U_h(φ)=exp(iφΩ_h),
γ(φ)=⟨U₁(φ)η,U₀(φ)η⟩.
```

The two reduced R₁ outputs have identical diagonals and off-diagonals `γ/2` and `γ*/2`, respectively. Their trace distance is exactly

```text
D_tr(ρ_R₁^(j=+),ρ_R₁^(j=−)) = |Im γ(φ)|.
```

This is strictly positive for sufficiently small nonzero φ in the **continuum**, for every normalized η. Indeed, on the common external Hilbert space,

```text
Θ₀−Θ₁ = 2I+0.8 E_5 σ_yᴮ ≥ 1.2I.
```

Let `H_max=49/6+2(M+0.4)≈11.906789`, with M from the integrated report. Operator monotonicity of the square root and the spectral theorem give the explicit bound

```text
Ω₀−Ω₁ ≥ √(Θ₁+1.2I)−√Θ₁
       ≥ [√(H_max+1.2)−√H_max]I
       ≈ 0.169708 I.
```

Since the bounded generators make γ norm-differentiable,

```text
γ(φ)=1+iφ⟨η,(Ω₀−Ω₁)η⟩+O(φ²).
```

The imaginary part is nonzero for all sufficiently small nonzero φ. The small-time interval can depend on η; the proof does not assert a nonzero distance at every φ.

For the earlier incident packet and initial D/M/B states, the N=80 calculation at φ=5 gives

```text
γ ≈ −0.455015+0.887553i,
D_tr ≈ 0.887553.
```

With equal priors, the optimal R₁-only discrimination success in this **different preparation** is `(1+D_tr)/2≈0.943777`. N=40,80,160 agree closely, but this number has no certified continuum error bound. The continuum small-φ nonzero result is the analytic argument above.

There is no contradiction with §2. The five-ray code state has a mixed confined record and a specially correlated work environment; that state remains protected. The new control starts with a coherent R₁ and a product work eigenstate outside that two-state code. The full h interaction then creates a legitimate causal channel in the specified model. The earlier fixed-record result cannot by itself establish that the record algebra is dynamically isolated for arbitrary states or that a physical subject boundary is fixed.

## 4. What this does—and does not—select

Under a **strict S-local report** requirement, the J-probe rule with reliable reports is incompatible with the actual phase-flip comparison. This gives a concrete way for an admissibility requirement to eliminate one candidate package rather than merely listing alternatives. The record-relative R rule is compatible with that locality test because it depends on the local record; this is not proof that R is experienced or that S is a subject.

Even after imposing the test and pairwise zero with equal incidence, R and its globally sign-reversed assignment `−R` both pass: for every r their values are `(r,−r)` and `(−r,r)`, respectively. The physical relations, locality condition and balance do not by themselves decide which is positively felt. This is a limitation of those specific premises, not a proof that zero's full constitution cannot determine the sign. It does not license treating a chosen sign, subject boundary, incidence measure or counterterm as an unexplained residue.

A constructive next step is to replace the old pairwise graph by a specified **full-interaction causal boundary rule**, test it on the protected and coherent preparations above, and examine whether its selected domains and their report interfaces remain consistent under changes of clock and under a genuinely local spacetime embedding. In parallel the account must explain why any selected domain has felt qualities and a justified whole-level signed measure. No result here establishes objective whole energy zero, experienced time, actual outcomes, a global experiential sum, or full gravity. Negative felt valence, if present, remains locally real even if a justified whole-level sum vanishes.
