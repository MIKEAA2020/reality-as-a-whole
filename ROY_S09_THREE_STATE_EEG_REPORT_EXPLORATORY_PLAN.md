# S09 three-state EEG/report pilot: fixed post-hoc plan

This plan is written after the S09 participant's reports and prior binary decoder were inspected, but before running the three-state analysis specified here. It is **not** prospective preregistration or an independent participant test. Labels and timing are provisional as in the [earlier nine-scan analysis](ROY_S09_EEG_REPORT_TRANSFER_RESULTS.md). The user already supplied these data; do not request them again.

## Fixed target and decoder

Use five assumed 42-second trials per scan, sample rate 250 Hz and nonoverlapping 2-second windows. Within each trial start unknown and carry each recorded code forward from `latency_s1`, `latency_s2`, `latency_s3`; require valid nonoverlapping events, valid trial bounds and a correct bad-epoch mask. Report labels 1, 2, 3 mean the release's two pure reports and mixed report; color/frequency/eye mapping is not needed to classify those codes and is not asserted as independently verified. A window gets a target label only if at least 75% of its samples share the same nonzero code; otherwise it is unresolved. Unknown samples count toward the full denominator, never as a report class. This ≥75% choice is a scoring convention, not a claim that the whole window had a single percept. Any artifact-marked sample requires decoder abstention.

Compute the same fixed POz lower/higher frequency-tag log-power ratio as in the binary pilot, for **all artifact-clean windows**, regardless of the eventual report label. Fit one mean per class on labeled, clean training windows. Predict the nearest of three training means, breaking exact ties by smallest code. Stop and diagnose if a class has no training samples or features are undefined; do not tune the model to rescue the result. Compare on the same windows with training-set majority and within-trial-position majority rules (ties and empty slots use global training majority). No test labels influence any fitting, threshold or model selection. The time-only baseline can exploit trial timing; it is not a causal control.

## Reports and limits

For each held-out scan and pooled test, report 3×3 confusion matrices, class counts and recalls, macro recall when all three test classes occur, overall accuracy on labeled clean windows, full-grid correct fraction, unknown/transition windows, artifact counts and any overlap. All three methods predict all artifact-clean windows; abstention is determined by artifact alone, not the report. The labeled-clean accuracy is conditional on the report-defined target being clear, not deployable label-dependent abstention. A full-grid correct fraction counts every unresolved or artifact-marked window as not successful; it is a conservative scoring convention, not error about experience, and report mixing itself is valid. Report unlabeled-clean predictions by class only in aggregate; no raw timestamps.

Scans and windows belong to one participant and are not independent experimental units. Results are descriptive, with no population p-values or confidence intervals. Prior binary test runs were inspected; this is an exploratory reuse of data, not a blinded held-out validation. A future cross-participant test must freeze all preparation, normalization, color/code alignment and baselines on development participants, then independently verify held-out participant schemas, report codes and condition mappings. No EEG/fMRI alignment or experiential error calibration is implied. Synthetic tests must cover feature extraction, threshold boundaries, equal ties, missing classes, artifact exclusion, full-grid accounting, label independence and fit-only use of training data.
