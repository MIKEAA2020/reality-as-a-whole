## 1. One zero and a sphere of null directions

Work temporarily in an effective Minkowski tangent space with signature `(-,+,+,+)`. Every nonzero future null vector can be written

```text
k = r(1,n),       r>0,       |n|=1.
```

Vectors differing by a positive factor determine the same future null ray, so the space of such rays is `S²`. Analogously to the earlier [point–sphere proposal](ZERO_POINT_INTERNAL_SPHERE_CONSTITUTION.md), use

```text
π(r,n)=r(1,n),     r≥0,
π(0,n)=0 for all n∈S².
```

The enlarged representation retains an `S²` boundary of directions while the projection sends it to a single zero vector. A Lorentz transformation sends null rays to null rays and the zero vector to itself, so the construction does not require an external preferred direction. The choice of an observer to write the particular coordinates `(1,n)` is a normalization convention; boosts change that normalization and the coordinates on the sphere.

**Important:** this zero is the zero vector in an already assumed effective tangent space. It is not automatically the whole of reality, zero energy, literal nothingness, or a physical event with no spacetime. The blow-up retains a richer direction space that the plain zero vector does not contain by itself. ## 2. How a cone of internal directions constrains physical geometry

There is a precise result supporting the idea that directions can encode more than a visual sphere. Suppose a symmetric quadratic form `A` on a four-dimensional vector space vanishes on the same future null directions as the Minkowski metric. In the coordinates above it must satisfy, for all unit `n`,

```text
A₀₀ + 2A₀ᵢ nᵢ + Aᵢⱼ nᵢnⱼ = 0.
```

Comparing `n` and `−n` gives `A₀ᵢ=0`. Choosing `n` along each coordinate axis gives `Aᵢᵢ=−A₀₀`. Choosing `n` with two nonzero components gives `Aᵢⱼ=0` for `i≠j`. Therefore

```text
A = c η
```

for an overall scalar `c`. If the same signature and time orientation are maintained, take the appropriate positive conformal scale. Thus the **embedded null cone fixes the local Lorentzian metric up to a scale**. The test code also checks that nine independent rational null-direction conditions have rank nine on the ten symmetric metric components.

This is a mathematically exact connection between a sphere of directions and local causal geometry. It does not derive a metric from an abstract sphere alone: we assumed a four-dimensional vector space, how the directions are embedded as null rays, and the cone structure. Nor does one local cone supply the manifold, dimensionality, connections between events, metric scale, matter, Einstein equations or a whole-history zero.

## 3. Internal relations without choosing an observer

The previous report used `n·m` as a rotationally invariant relationship. That is useful **within a selected observer's rest frame**, but angles between light rays generally change under a Lorentz boost. Rotational invariance is not the same as invariance under all changes of inertial observer. This distinction is important for the user's no-preferred-foliation requirement.

A stronger internal relation uses four *physically distinguished* null directions. Represent directions by complex stereographic coordinates `z₁,…,z₄`. A proper orthochronous Lorentz transformation acts by a common Möbius transformation

```text
z ↦ (az+b)/(cz+d),       ad−bc≠0.
```

The cross-ratio

```text
X = (z₁−z₂)(z₃−z₄) / [(z₁−z₃)(z₂−z₄)]
```

is unchanged. For instance, ordered directions `(0,1,2,3)` have `X=1/4`, while `(0,1,2,−1)` have `X=3/4`. Those are distinct relational configurations under common proper Lorentz transformations, although each direction set belongs to the same celestial sphere. A common Möbius transformation changes the individual coordinate labels but not `X`.

Thus internal differences need not rely on an externally preferred axis or clock frame. However, the four roles must have a physical basis; reordering them can change the cross-ratio. The number of directions, their incidence, their physical realization and their experiential meaning do not follow from the sphere alone. The expression is not a valence, probability or consciousness measure. No actual subject is established by selecting four rays.

## 4. A correction to simple spherical probabilities

A uniform angular measure in one inertial observer's sky is rotationally invariant in that frame, but **is not invariant under every boost**. Let `t=cosθ` have the uniform density `1/2` on `[-1,1]`. For a boost of speed `β` along the axis,

```text
t' = (t−β)/(1−βt).
```

Then `t'>0` iff `t>β`. At `β=3/5`, the original uniform distribution puts probability `1/5` in the boosted positive hemisphere, rather than `1/2`. Since the normalized rotation-invariant measure on `S²` is unique, no single normalized distribution on the sphere is invariant under **all** rotations and boosts.

This corrects a possible overreading of the previous uniform-sphere example: a rotation-symmetric count does not by itself give a frame-independent self-location rule. It does **not** forbid a covariant probability law whose state, observer or measure transforms appropriately, nor an emergent physical rest frame defined by actual matter. It says that such a law or frame requires a substantive basis; it cannot be read off from a bare round sphere.
