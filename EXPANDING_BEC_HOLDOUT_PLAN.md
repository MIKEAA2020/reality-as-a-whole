# Preregistered-in-workspace exploratory ramp-holdout plan

This plan was written before calculating the ramp-prediction scores. It is not externally timestamped preregistration and the underlying published data and earlier sampling audit are already known, so the outcome is exploratory. The experiment and this subsequent analysis do not test quantum-gravity time.

## Input and split

Use all `All` dynamic files in the pinned Banik source and deduplicate the seven `Initial` controls. Use the four time slices strictly inside the programmed 10 ms transition (1 ns endpoint tolerance) as the **outcome holdout**. Fit each dynamic trace's nuisance initial conditions only to all other time slices, including pre- and post-ramp measurements. This is interpolation using a specified dynamics, not a forecast from the initial state. The decoder's per-slice reference-normalized 1D profiles are the measured outcome; project onto spatial sine and cosine with the decoded angle axis. Fit both fixed spatial quadratures with their own two initial-state coefficients, without importing an angular phase estimated from the complete data. These spatial quadratures are not two temporal quadratures measured in a single shot.

## Locked reference models

Use the experiment's published linear phonon ODE and error-function radius program as implemented in its source code, not a new derivation. In both models, set the speed scaling exponent `alpha=0.5`, corresponding to the harmonic-trap reference discussed in the paper. Set `gamma_H=0.5` in model H and `gamma_H=0` in model Z. This is a comparison of **fixed reference models**, not a re-estimation of the published Hubble coefficient. Do not use the paper's full-dataset parameter estimates, which included the held-out slices.

For each dynamic trace estimate initial and final radii from its non-ramp plateau radius means. Take initial frequency and initial/final quality factors from the nearest-radius static-control object's `fi` and `Qi`; correct the damped frequency for the fixed Q before propagation. Scale sound speed by `(R/Ri)^(-alpha/2)` and `(N/Nref)^(alpha/2)` as in the authors' `SoundSpeed.m`. `Nref` is the mean atom number of the initial-radius static control. Dynamic N(t) is linearly interpolated **only from non-ramp time slices**, with constant extrapolation to t=0 and after the last training time. The fixed frequency, Q, radius and number inputs are treated as plug-in quantities, not independently known exactly; their uncertainty is not captured by the conditional intervals below. Static controls contain the authors' pre-fitted `fi` and `Qi`, so any unverified leakage or fit conventions in those fields are limitations. Use plateau estimates rather than held-out radius or phonon observations. Interpolate Q linearly between the two plateau radii.

Integrate two fundamental solutions per trace, representing independent initial `chi` and `chi_dot` at t=0. The predicted signed 1D phonon amplitude follows the authors' `R^alpha chi_dot`. Apply ordinary least squares independently to the two Fourier channels on non-ramp time slices. Require a full-rank scaled design; report the design condition number. Do not use the decoded full-data temporal or angular fit parameters.

## Error checks and summaries

Estimate each per-time-slice, per-channel shot variance from the individually extracted raw 1D phonon profiles, using decoded reference profiles and run membership; divide by the actual number of preparations to obtain an estimated variance of the mean. This does **not** include the uncertainty of the common reference profiles, frequency calibration, radius, atom-number trajectory, shared drift, detector systematics or dependence across time. No fabricated independent observations.

Validate the fixed-design computation by synthetic Gaussian draws around model H at the actual time points, with the estimated per-slice variances treated as known, using the same train/holdout split. Require the true generating coefficients to be recovered in aggregate, full rank, and empirical coverage of nominal 95% marginal prediction intervals between 92% and 98%; use a fixed random seed. This is a conditional programming/coverage check, not validation of Gaussian noise or real-data uncertainty. If the test fails, do not interpret experimental scores.

For actual data, report both models' held-out root-mean-square errors for the two spatial Fourier components, separately by branch, and paired protocol-cluster bootstrap intervals on the difference `RMSE_H − RMSE_Z` (negative favors H). Resample whole protocols within each branch with a fixed seed; these intervals quantify protocol-to-protocol variation conditional on the common calibration and reference preprocessing, not total uncertainty or independent replication of the seven shared controls. Also report nominal conditional marginal prediction-interval coverage as a diagnostic only; no p-value or claim of physical exclusion is permitted. Show how many actual training designs are ill-conditioned and inspect sensitivity to assumed static calibration before drawing any stronger conclusion. No temporal-phase residual at unobserved radius is claimed.

## Known limitations

This is a simplified two-quadrature reduction of the paper's 2D global fit, with per-trace initial states and fixed model coefficients. The reference profiles are shared across runs and can be estimated from other time slices; this creates correlations and the bootstrap does not propagate them. Static `fi` and `Qi` fits, physical calibration, preprocessing and the MATLAB decoder have not been independently reproduced against the authors' complete MATLAB implementation. Missing full covariance means any apparent preference or interval is exploratory, not a measured new effect. A fit using post-ramp data cannot establish that pre-ramp phase alone predicted the transition. Compare with the 2018/2022 papers before any novelty claim.
