# Fixed bounded audit: pain and aversion data as an experiential anchor

## Aim and limits

Inspect the pinned [ds008349 v2.0.1 dataset](https://doi.org/10.18112/openneuro.ds008349.v2.0.1), commit `3252827891885aa1890e6b1531a2d3aeefeaa5fd`, as a possible same-participant, cross-modality test of a future independently measured physical mismatch. Do not download raw EEG, video/audio or all annexed ratings. The [Champagne et al. preprint](https://doi.org/10.64898/2026.09.29.755497) and this work are not peer-reviewed or externally preregistered. Its methods and part of the results, metadata tree, participant-table schema and one participant's sample event files were inspected before this plan. Its aggregate report values were already visible; all calculations are retrospective, not blinded.

## Bounded input and checks

Download the pinned GitHub metadata-only codeload archive with a strict 15 MB compressed limit. Inspect only the regular event TSVs for `audioactive` and `thermalactive`; never dereference symlinks, execute code, or print individual data, questionnaire items, demographic traits, session comments or test dates. Verify each event-file Git blob against the GitHub recursive tree at the same pinned commit, stop on truncation or hash mismatch. Compute subject/session counts, schema exceptions, event code sequences and clock alignment errors relative to the sidecar's declared 1 kHz; report aggregate distributions only. Distinguish files present in the Git tree from validated data available at the full dataset host. Do not treat the fact that an EEG/ratings path exists as signal access.

For each active task require exactly the sequence `t01/p50, t02/p150, t03/p100, t04/p50, t05/p150, t06/p100, t07/p150, t08/p50, t09/p100, t10/end`, one occurrence per row, nonnegative strictly increasing event times, and unique subject/task path. Count exceptions; no exclusion or recoding selected for a favorable result. Count original 50 Hz rating TSV symlinks and EEG data symlinks by task via the tree, and distinguish them from actual annex contents. The target's availability and subjective instructions must come from source methods, not path names alone. The participant table is not used for outcome analysis.

## Published mean contrast

The preprint reports three **group means** per modality: thermal pain `[28.11,64.76,111.00]` and auditory unpleasantness `[30.62,86.08,157.99]` at nominal targets `[50,100,150]`. Their target anchors and reported population sizes need not be identical, and a shared numeric metric across modalities is not established. Treat the values as rounded published group means, not individual pairs or matched observations. Calculate the differences and a purely algebraic oracle lower bound for any three-number model forced to give the same mean to both modalities at each target, on these six displayed means. The midpoint gives the smallest possible RMSE over the six displayed summaries. Do not treat that as individual-level prediction performance, a statistical test, evidence of modality matching, or a test of the physical mismatch hypothesis. State rounding and sample-composition limits. This is a negative control for a narrow, explicitly named shortcut: numeric VAS target labels alone determine both modality-level report means identically.

## Decision gate

A feasible future test would need actual independently identified coupling preferences, appropriately timed EEG, audited stimulus and rating alignment, and a noncircular physical-to-experiential calibration. The study contains pain-intensity ratings for heat but unpleasantness ratings for sound; task names cannot be treated as an identical phenomenal target. The passive task precedes active rating, so order and self-report motor/attention effects cannot be separately randomized from one another; no direct passive-trial concurrent valence ground truth is promised. Fixed within-task level order gives stimulus-time confounding and makes random adjacent-window splits unsafe. All are limits, not dismissal of first-person experience. This dataset cannot alone derive subjects or determine B4–B5.
