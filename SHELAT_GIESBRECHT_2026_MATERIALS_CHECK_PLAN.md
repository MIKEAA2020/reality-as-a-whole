# Retrospective plan: checking the 2026 attention study's shared materials

This plan follows the supplied paper and [main-paper audit](SHELAT_GIESBRECHT_2026_SUSTAINED_ATTENTION_AUDIT.md); the reported results and exploratory status are already known, so this is a retrospective verification, not a blind or prospective analysis.

1. Inspect the authors' public OSF folder listings and reported experiment registrations. Record exactly which files or registration text are retrievable, versions, and any access or transport limits. Never imply listed data were analyzed.
2. Prioritize the code and metadata relevant to rare-trial exclusions, trigger definitions, randomization and pooled logistic models. If usable trial data and scripts can be retrieved, assess whether their variables, sample and estimates reproduce the published results; separate verified reanalysis from code inspection and report every discrepancy and unperformed step. Do not manufacture inaccessible data or infer a file's contents from its name.
3. Check any supplementary or preregistration details needed to interpret the experiment-2 confirmation, subgroup, and convergence caveats. Do not treat a failed fetch as absence of a file or as a failure to preregister.
4. Update the source audit and project implications only where the new evidence warrants it. If any important material cannot be fetched, provide the user with exact titles and best available links; do not request files merely because optional analysis was not pursued.
5. Run suitable mechanical checks, refresh inventories after durable changes, and preserve the distinction among task-specific behavior, phenomenal conjunction, private-token subject incidence and q-quality. No toy model substitutes for source evidence.
