# Plan: remaining PAINgen mismatches and run completeness

## Question and chronology

The [RT reconstruction](PAINGEN_RESPONSE_TIME_RULE_RECONSTRUCTION_AUDIT.md) left 35 finite paired condition means unmatched, all without a common nonempty subset witness among the accepted events. A candidate explanation is that the conservative parser rejected a run, or a run is absent in the pinned BIDS release, so its trials never entered the candidate set. Before calculating any new stratum, characterize whether these 35 keys actually coincide with incomplete *relevant* runs. This is a retrospective, outcome-informed diagnostic, not a blinded hypothesis test. No claim is made that incomplete runs cause discrepancies.

## Fixed procedure

Reuse the exact pinned and checked tree/archive, author CSV, parser, join, tolerance, RT candidate and existing exhaustive subset checker. Enforce reproduction of 1,574 event files, 1,566 accepted runs, 12,528 episodes, 4,707 overlapping keys, 307 missing exports, 4,400 eligible keys, 4,365 screened paired matches, and 35 remaining pair mismatches, all 35 no-common-subset cases. Abort on duplicate person/run or source keys, inconsistent ratings, missing RT or unexpected prior counts; do not relax grammar, invent values, examine demographics or run outcome-driven maps.

For every eligible cell, mark each of its two expected treatment runs (`01` and `04` control; `02` and `03` placebo) as accepted, present-but-rejected by the existing grammar, or absent from the pinned event-file tree. Categorize cells as two accepted, one accepted and one rejected, or one accepted and one absent; stop on any impossible category for an overlapping eligible cell. Stratify **all eligible keys**, not only the selected 35, by these categories and by screened paired match/mismatch. Also count distinct represented people per category within mismatch and match groups, without adding those people across categories (the same person may contribute multiple keys or groups). Record mismatch dimension (both, intensity only, unpleasantness only), category distribution by modality/treatment, and RT-retained trial count for the 35. Summaries are counts, not confidence intervals, effect estimates or causation tests. Keep identifiers and trial rows in memory only, write aggregate results only.

This diagnostic does not inspect rejected runs' trial contents. It cannot show whether a rejected file contains usable trials or whether they were used in the export. An absent file does not imply an absent experiment. If results motivate further parsing, document an additional post-result plan **before** inspecting those contents and do not call the change preregistered. If the 35 are unrelated to missing/rejected runs, say so. Even a perfect co-occurrence cannot prove the generating pipeline.
