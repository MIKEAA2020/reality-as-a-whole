# Fixed retrospective plan: stimulation and reported visual qualities

## Aim

Use [ds005169 v1.0.0](https://doi.org/10.18112/openneuro.ds005169.v1.0.0), GitHub commit `ff529027bef934f384e7385f1b83d7190ef307d0`, to test a **restricted metadata shortcut** on the same report-bearing clinical stimulation dataset: are reported visual-content annotation flags predictable from stimulation current alone, without patient-specific fitting or neural data? This is a first-person report interface benchmark, not a test of valence, q, phenomenal constitution or the complete framework. The related paper is [Mihai et al.](https://doi.org/10.1016/j.brs.2025.05.138). We read the main paper through the discussion, inspected the dataset README, full tree paths and two example event files and one event sidecar before this plan; numerical analysis of the remaining event data has not yet been run. Results are retrospective and not prospectively preregistered.

## Bounded metadata inspection

Obtain the pinned GitHub recursive tree and a metadata-only codeload archive with a 10 MB compressed cap; no EEG, MRI, annex contents or executable external code. Verify the Git blob hash for each regular event TSV and its event JSON against the pinned tree, and do not extract symlinks. Work in memory and print only aggregates, not individual reports, patient IDs, labels, contacts or clinical narratives. Identify participant and session from the path; require unique subject/session and the declared `pre`, `stimulation`, `post` event schema. Report malformed inputs instead of recoding them. Extract finite current in mA, onsets and durations, and all binary `sym_` columns from the single non-pre/non-post row; `0` and `1` are **the repository annotations**, not assured negative/positive phenomenal truth. Stop if selected primary annotation columns have missing or nonbinary values; report sample exclusions only as explicitly defined. Record whether each path's corresponding iEEG BrainVision signal and header are symlinks and how many files are positive-only based on the dataset's explicit inclusion description, not an inferred negative class.

Check the fixed event schema and counts, timing and annotation availability, whether first-person effect text exists in every stimulation row, how many sym fields have one values, and specifically whether event sidecar descriptions distinguish `sym_color` and `sym_non_color` (compare the literal descriptions; do not silently change them). A stimulation marker `duration=0` is a point, not an observed absent stimulation; no duration or neural timing may be inferred from that alone. Report source discrepancies, tree and archive hash, and whether negative, lower-intensity or sham trials are actually present in the inspected event files without treating their absence from these files as evidence of no author-collected controls.

## Primary held-out comparison

For the 4 existing binary annotations `sym_static`, `sym_dynamic`, `sym_continuous_hallucination`, `sym_intermittent_hallucination`, evaluate:

- `constant`: the training patients' pooled mean for that annotation.
- `current_bin`: training mean for a prespecified dose bin `(current ≤ 1 mA, current > 1 mA)`; if a bin has no training samples, fall back to the training mean. Threshold chosen as a simple fixed round dose after seeing paper methods and two sample schemas, not fitted or externally preregistered.

Use leave-one-**patient**-out; all of one patient's sessions remain in the same test fold and no test patient contributes to training. Pool held-out Brier loss over sessions for each annotation, then provide mean across four annotations; report sample counts and fallback counts. This is retrospective, conditional on included selected positive-effect cases, not a validation of neural signatures or model of experience. Report raw Brier scores rather than favorable percent improvements and do not add optimization or extra predictors after inspecting outcomes. No statistical significance, confidence interval, population-wide performance or independent replication is claimed. Current is an intervention setting, not a measured internal mismatch. Common-trigger, selective sampling, repeated sessions, nonrandom stimulation intensity and disease remain confounders.

## Additional in-sample negative control

For each chosen annotation, independently minimize the number of event-flag mistakes of an oracle that must give the same binary output for every row sharing both subject and exactly the same recorded current; calculate the aggregate fraction and the number of repeated-current groups with mixed annotations. The oracle is allowed to inspect all test labels and choose a separate within-subject value per current, so the lower bound is **optimistically in-sample**, not held-out model performance. It demonstrates only whether recorded current plus patient identifier determines the *published annotation* on these events; site, stimulation timing and brain state may differ and are not held fixed. No inference that equal brain states produce different experiences.

If eligibility fails, retain explicit reasons and do not force a result. Document trial-selection effects and difference from the paper's broader 130 stimulations/22 people and 115 qualified sites/20 people. Paper explicitly reports collecting lower-intensity negative controls; verify actual repository annotations and do not equate absence from our narrow event-file scan with absence from the study. For any signal-based causal or phenomenological comparison, require raw paired control signals, independent stimulation artifacts validation, realistic site/selection factors, an experience-respecting rival and appropriately calibrated reports. No additional invasive intervention is recommended.
