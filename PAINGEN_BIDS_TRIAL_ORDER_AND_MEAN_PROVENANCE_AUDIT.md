# PAINgen trial order and condition-mean provenance

## Decision

The released BIDS events support a **recorded trial-level link** between the two separately prompted ratings: after sorting by recorded onset and applying a conservative sequence screen, 12,528 episodes each have a stimulus row carrying both values and two subsequent rating events carrying matching values. The recorded order is almost balanced overall. This improves the provenance of the event-file ratings, but does **not** independently verify the underlying hardware, original behavioral logs, simultaneous feelings or causal independence of the two responses.

A more consequential unresolved issue is that our provisional reconstruction of simple trial means does **not** reproduce all the authors' condition-mean export: among 4,400 overlapping keys with both finite reconstructed and exported values per outcome, 610 intensity means and 608 unpleasantness means differ beyond `10⁻¹⁰`. The cause is not identified. The previous prediction results remain correct calculations **on the authors' exported table**, but should not be described as independently reconstructed from all BIDS trials or treated as a validated trial-level benchmark. This discrepancy is not by itself evidence of an error in the authors' study; exclusions, differing preprocessing, source versions or our reconstruction assumptions may matter.

## 1. Sources and audit sequence

The paper-cited dataset is [OpenNeuro ds004746 v1.0.0](https://doi.org/10.18112/openneuro.ds004746.v1.0.0); we inspected its GitHub mirror at commit [`8a38ee30b870373547676bf0d0638e16160472a1`](https://github.com/OpenNeuroDatasets/ds004746/tree/8a38ee30b870373547676bf0d0638e16160472a1). The dataset metadata declares CC0. The paper's source and prior complete reading are documented in the [full-paper audit](BOTVINIK_NEZER_PLACEBO_FULL_PAPER_AUDIT.md). The behavioral condition table is the author repository's `merged_firstlvl_stim_betas_to_share.csv` at commit `da46f2f9739ad2e9eeb9658711582be6357c1026`, SHA-256 `b40b4a1b1e001f2317fea07a49c6ee6de062f181a20affe149fe50a81b58545b`. Its README defines the intensity and unpleasantness columns, modalities and level coding. It is the same shared-provenance source used in the [earlier export cross-check](PAINGEN_UNPLEASANTNESS_BASELINE_AND_MISMATCH_GATE.md), not an independent study.

Before the [fixed plan](PAINGEN_TRIAL_PROVENANCE_ORDER_FIXED_PLAN.md), we inspected the dataset trees, metadata, and one run's event schema and class counts. The initial plan conservatively required file rows already be chronological. That initial analysis rejected **1,572 files for decreasing onsets**, one for row count and one for schema, accepting no episodes. Inspection of the previously examined example showed that source row order can list the two rating rows in an order different from their onset times. We then wrote a transparent [post-inspection amendment](PAINGEN_TRIAL_PROVENANCE_ORDER_PLAN_AMENDMENT.md): sort by recorded onset, reject equal-onset ties, and only then enforce the episode grammar. No order statistics, rating association or condition-mean comparison had been calculated before this amendment. The later discrepancy stratification was itself added **after** the mismatch counts were observed. This is a retrospective source audit, not preregistration or outcome-blind replication.

The nontruncated v1.0.0 Git tree lists 1,574 ordinary event-file blobs. We read them from a 2,954,589-byte archive without extracting it, checking each file's size and Git blob hash against the tree. The compressed archive SHA-256 is `b8a04bcc0130edcd65067ccdc98e6f480b403f6165417898f8292f48148a8be7`. A preliminary tree-only comparison found that all 1,574 event paths and blob hashes match release 1.0.1; it does not establish that other files or the complete releases are identical. We did **not** read MRI, participant demographic data, experimenter logs or original task source code. The event records and participant identifiers are not copied into this repository.

## 2. What the exported event sequences support

The amended parser accepted **1,566 of 1,574** files; seven failed its exact 32-row screen and one lacked required schema. The retained files represent 394 people and **12,528 episodes** (eight per accepted run). Of all 1,574 files, **1,572** have at least one inversion in their original row-onset order. That is a warning against inferring question order from file line order; the count is not a claim that timestamps or the research design are invalid.

Each accepted episode contains a warning cue, one heat or pressure event, then exactly one intensity and one unpleasantness rating event according to strictly increasing **recorded onset**. The stimulus-row intensity value equals the intensity-event value in all 12,528 episodes, and the corresponding unpleasantness values likewise agree in all 12,528, to tolerance `10⁻¹⁰`. All these values are finite and within 0–1. These are duplicated fields in a shared export, so agreement tests internal consistency, not independent verification of what participants entered. The grammar excludes ambiguous or incomplete files rather than imputing values; no inference is made about the eight excluded files.

| Earlier recorded rating event | Episodes |
|---|---:|
| Intensity | 6,200 |
| Unpleasantness | 6,328 |

All 394 people represented in accepted runs have **both** orders somewhere in their retained events. For every accepted episode, the first rating's recorded onset plus its recorded positive duration is at or before the second's onset. The exported onsets therefore support sequential, rather than simultaneous, **rating events**. They do not establish whether the experience changed between questions, when the original sensory episode ended, whether a response influenced the next, or the mechanism of randomized assignment. These are not 12,528 independent people.

Recorded event durations have medians of **1.017 s** for the cue, **12.907 s** for heat, **10.060 s** for pressure, **2.966 s** for intensity ratings and **2.882 s** for unpleasantness ratings. The cue interquartile range is 1.0167–1.0168 s; heat is 12.515–12.996 s and pressure 10.040–11.042 s. These are descriptive BIDS event durations, not independently calibrated stimulus delivery, thermode plateau durations, experimental timing settings or isolated response times. In particular, heat events can encompass more than a sustained plateau. They are relevant to the [paper audit's timing discrepancy](BOTVINIK_NEZER_PLACEBO_FULL_PAPER_AUDIT.md), but do **not** settle which duration description refers to which part of the experimental procedure.

## 3. Provisional reconstruction of condition means

We mapped runs 01 and 04 to control and 02 and 03 to placebo, as described in the paper; heat levels 46.5, 47 and 47.5 to coded levels 3, 4 and 5; and pressure event codes 3, 4 and 5 to the same condition labels. The latter are coded event levels for this join, **not** verified pressure in kg/cm². We averaged valid stimulus-row ratings separately within literal person × modality × coded level × treatment keys, with no imputation and only retained runs. This is a candidate reconstruction, not a claim that the source authors used the same inclusion rules or weighting.

| Comparison with behavioral export | Intensity | Unpleasantness |
|---|---:|---:|
| Finite means equal within `10⁻¹⁰` | 3,790 | 3,792 |
| Finite means unequal | 610 | 608 |
| Export missing but reconstructed mean finite | 307 | 307 |

There are 4,707 keys on both sides, no reconstructed-only keys, and two export-only keys. The largest absolute difference among finite pairs is **0.51367** on the recorded 0–1 scale; no claim is made that this is a cardinal difference in suffering. Both ratings are unequal for 598 keys, only intensity for 12 and only unpleasantness for 10; both are equal for 3,780, and at least one export mean is missing for 307. These categories exhaust the 4,707 common keys. The number of retained valid trial ratings per reconstructed condition mean ranges from one to six; **2,574** reconstructed keys have three, **1,684** have two and **130** have one. This is not an assertion that the export used that number or those same trials.

The explicitly post-result stratification finds **598 keys with at least one unequal dimension even among people with all four runs accepted**: 578 have both dimensions unequal and 20 have one unequal. Thus the difference is not accounted for merely by our exclusion of incomplete runs. It also occurs in both thermal and mechanical conditions and in both treatment categories; the [receipt](verification/paingen_trial_provenance_audit.json) gives the counts. A subsequent [paired-subset diagnostic](PAINGEN_CONDITION_MEAN_SUBSET_PROVENANCE_DIAGNOSTIC.md) finds that 585 of the 620 mismatched keys have a common proper-subset witness within the stated numerical tolerance, while 35 do not. This is arithmetic consistency, not identification of the actual inclusion process. We have not found and verified the transformation from the event files to the published export, nor independently authenticated actual stimulus delivery or response records. There is no basis here to choose a correction, silently replace the authors' means, or assign blame.

## 4. Implications for the project

- The previous [intensity–unpleasantness benchmark](PAINGEN_INTENSITY_UNPLEASANTNESS_COMMON_INTERFACE.md) used the authors' condition table and reported family-held-out prediction on that table. This audit does not refute its computation. It limits any stronger claim that the benchmark has been reconstructed or validated against all event-file trials. Its missing-row and conditioning caveats remain, now joined by this explicit provenance gap.
- If further trial-level analysis is pursued, first locate the actual first-level behavioral import and exclusion code or obtain an author-documented mapping. Verify per-trial and per-condition inclusion, actual run and treatment labels, missingness, scale transformations, source version, and the two unreconstructed keys. Re-run against appropriate samples without exposing individual data; then freeze a separate order-effect estimand and clustering strategy. Do **not** choose a trial filter simply to maximize agreement and then present it as independently validated.
- The BIDS fields give a potentially useful recorded order for future analysis, but near-balanced counts are not a randomization audit or evidence that order has no effect. A proper order comparison needs verified assignment, same-person history and condition controls, family dependence and appropriate missingness; a raw trial-level correlation or 12,528-row significance test would be inadequate.
- Neither reconstruction nor a resolved discrepancy would measure the proposed physical mismatch `q`, establish a quality identity, select a subject boundary, or distinguish rival metaphysical grounds. Participants' reports are important evidence of real experience; a provenance discrepancy concerns the recorded transformation, not the reality of their pain.

## 5. Reproduction and current status

The [checker](verification/paingen_trial_provenance_audit.py), [tests](verification/paingen_trial_provenance_audit_test.py), and aggregate [receipt](verification/paingen_trial_provenance_audit.json) implement the amended procedure. Obtain the pinned recursive tree with `gh api 'repos/OpenNeuroDatasets/ds004746/git/trees/8a38ee30b870373547676bf0d0638e16160472a1?recursive=1' > TREE` and the pinned archive from `https://codeload.github.com/OpenNeuroDatasets/ds004746/tar.gz/8a38ee30b870373547676bf0d0638e16160472a1` into `ARCHIVE`; then run `PYTHONPATH=verification python verification/paingen_trial_provenance_audit.py --tree TREE --archive ARCHIVE`. `--behavior PATH` accepts the exact pinned author CSV instead of fetching it. The checker rejects a changed tree or archive digest, unexpected members, unsupported level codes, duplicate person/run keys and tied onsets; no MRI is downloaded. Execute `PYTHONPATH=verification python -m unittest -v paingen_trial_provenance_audit_test` for parser and aggregation tests.

The metadata archive's consistency is not external validation of biological or subjective truth. B4–B5/F2, B9/F3 and B10 remain open; C3 still requires full structural **and** experiential intelligibility. No new clinical outcome, trial-level mismatch analysis, causal effect, or framework proof is claimed.
